clipper

A personal desktop tool for publishing short gaming clips.

What it is

clipper is a private desktop application that runs on its owner's own Windows computer. It cuts short vertical clips from live game streams the owner watches, adds subtitles and captions, and publishes the finished videos to the owner's own YouTube channels (as Shorts) and TikTok accounts.

How it uses YouTube and TikTok

  • It signs in only to accounts that belong to the owner, through the official Google and TikTok sign-in pages.
  • It uploads videos created by the owner to those accounts using the official YouTube Data API and TikTok Content Posting API.
  • It reads the owner's channel name and the view counts of videos it uploaded, to show statistics inside the app.

clipper is not a public service: it has no user registration and is not offered to other people. All data stays on the owner's computer.
